# 🌧️ Rainy Day Snacks Community

A beautiful community website built with React and Tailwind CSS where users can share their favorite rainy-day snacks and drinks.

## ✨ Features

- **Browse Snacks**: Discover a variety of comfort foods and drinks
- **Add New Snacks**: Share your favorite rainy day treats with the community
- **Search & Filter**: Find snacks by name, category, or ingredients
- **Interactive Cards**: Like, comment, and rate snacks
- **User Profiles**: Manage your shared snacks and preferences
- **Responsive Design**: Works perfectly on all devices
- **Modern UI**: Built with Tailwind CSS for a beautiful, modern look

## 🚀 Getting Started

### Prerequisites

- Node.js (version 14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd rainy-day-snacks
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

4. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## 🛠️ Tech Stack

- **Frontend**: React 18 with JSX
- **Styling**: Tailwind CSS
- **Routing**: React Router DOM
- **Icons**: React Icons
- **Notifications**: React Hot Toast
- **State Management**: React Context API

## 📁 Project Structure

```
src/
├── components/          # Reusable UI components
│   ├── Header.jsx      # Navigation header
│   ├── Footer.jsx      # Site footer
│   ├── SnackCard.jsx   # Individual snack display
│   └── SearchBar.jsx   # Search and filter component
├── pages/              # Main page components
│   ├── Home.jsx        # Homepage with snack grid
│   ├── AddSnack.jsx    # Add new snack form
│   ├── SnackDetail.jsx # Individual snack details
│   └── Profile.jsx     # User profile page
├── context/            # State management
│   └── SnackContext.jsx # Global snack state
├── App.jsx             # Main app component
├── index.jsx           # App entry point
└── index.css           # Global styles with Tailwind
```
